Ví dụ file TOC
JSON Format (Array):
[
  {"title": "1 Introduction", "start": 1},
  {"title": "2 Intelligent Agents", "start": 34},
  {"title": "3 Solving Problems", "start": 64}
]
JSON Format (Nested):
{
  "1 Introduction": 1,
  "Part II": {
    "2 Intelligent Agents": 34,
    "3 Solving Problems": 64
  }
}
TSV Format:
1	1 Introduction
34	2 Intelligent Agents
64	3 Solving Problems
Lưu ý: Dùng ký tự TAB giữa số trang và tên chapter
Giải thích Page Offset

Nhiều PDF có phần đầu (bìa, bản quyền, mục lục) trước nội dung chính.

Ví dụ:
  • Trang PDF 1-16: Bìa, bản quyền, mục lục
  • Trang PDF 17: Trang sách "1" (Chapter 1 bắt đầu)
  • Trang PDF 50: Trang sách "34" (Chapter 2 bắt đầu)
Giải pháp: Đặt Page Offset = 16. File TOC dùng số trang sách (1, 34, 64...), tool sẽ tự động tính số trang PDF (17, 50, 80...)
Định dạng file output

Tên file PDF tự động dựa trên tên chapter:

Nếu chapter có số:
"1 Introduction"           → Ch01_Introduction.pdf
"2 Intelligent Agents"     → Ch02_Intelligent_Agents.pdf
"27 Philosophy Ethics AI"  → Ch27_Philosophy_Ethics_AI.pdf
Nếu chapter không có số:
"Preface"       → Part_01_Preface.pdf
"Appendix A"    → Part_02_Appendix_A.pdf
