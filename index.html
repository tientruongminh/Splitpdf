PDF Chapter Splitter

Split a PDF into chapter PDFs using a TOC of start pages. Matches the semantics of your main.py script.

Large files are supported. The server performs the split.
JSON supports list or dict, nested dicts will be flattened. TSV uses lines like start\tTitle.
If book page 1 is PDF page 17, use 16.
Server will create this folder and save results there.
How it works
  1. This page posts your files to /api/split using multipart/form-data.
  2. The backend should call your Python splitter with the provided arguments and stream logs.
  3. When completed, the backend can respond with a JSON summary and optional download links or a zipped folder.
Tip: if you need a ready server, create a minimal Flask endpoint that imports your module and invokes split_pdf. I can provide that if you want.
